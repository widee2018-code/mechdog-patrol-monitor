# MechDog 연결과 Wi-Fi 조종 가이드 (Thonny)

MechDog 메인보드에 Thonny로 연결해서 `firmware/dog_cmd.py`를 실행하고, 노트북에서 Wi-Fi로 움직이는 방법입니다. 행동 알고리즘 전체 순서는 [brain/README.md](../brain/README.md)를 보세요.

```
노트북 키보드/카메라  →  brain/teleop.py, marker_follow.py  →  Wi-Fi(UDP 9100)  →  로봇견 dog_cmd.py  →  dog.move(속도, 회전)
```

## 1. 배터리와 USB

| 할 일 | 배터리 스위치 | USB |
|---|---|---|
| Thonny 연결, 파일 확인, 코드 실행 준비 | 꺼도 됨 (USB가 메인보드에 전원 공급) | 연결 |
| 명령으로 걷게 하기 | **켜야 함** (서보 모터 12개는 USB 전원으로 못 움직임) | Thonny 출력을 보려면 연결 유지 |

### 저전압 경고음(삐 소리)이 날 때

| 상태 | 의미와 할 일 |
|---|---|
| 스위치 OFF + USB만 연결 + 경고음 | USB 전원만으로 켜져서 배터리가 없다고 읽히는 경우가 많음. 코드만 올릴 거면 무시해도 됨 |
| 스위치 ON + 경고음 멈춤 | 배터리 괜찮음. 진행 |
| 스위치 ON + 경고음 계속 | **배터리 부족. 충전 후 진행.** 이 상태로 걸으면 서보 떨림, 보드 재부팅, Wi-Fi 끊김이 생길 수 있음 |

- 충전은 전용 충전기로, 스위치를 끈 상태에서 합니다.
- 7.4 V 리튬 배터리(2셀) 기준으로 완충은 약 8.4 V, 6.8 V 이하면 충전이 필요합니다(일반 기준, 정확한 경고 기준은 Hiwonder 문서 확인).
- 스위치를 켜면 로봇견이 기본 자세로 서려고 움직일 수 있으니 몸통을 들고 있거나 받침대에 올려 두세요.

## 2. Thonny 연결

### 케이블
- MechDog **메인보드**의 Type-C 포트에 연결합니다. 카메라 모듈(ESP32-S3)은 다른 보드입니다.
- 충전 전용이 아닌 **데이터 케이블**이어야 합니다.

### 인터프리터 설정
1. **Thonny → Settings…**(macOS) 또는 **도구 → 옵션**(Windows) → **Interpreter** 탭
2. 인터프리터 종류: **MicroPython (ESP32)**
3. Port:
   - macOS: `usbserial-xxxx` 또는 `wchusbserial-xxxx`가 들어간 항목 (예: `/dev/cu.usbserial-1120`)
   - Windows: `COM3` 같은 항목
4. OK

더 간단하게: Thonny 창 **오른쪽 아래 구석**의 인터프리터 이름을 클릭해서 `MicroPython (ESP32) • <포트>`를 고릅니다.

포트가 안 보이면: 데이터 케이블로 교체 → 다른 USB 포트 → USB-시리얼 드라이버(CH340 또는 CP210x) 설치 순서로 확인합니다.

### 원래 프로그램 멈추기
MechDog은 켜지면 원래 `main.py`(앱 블루투스 조종)가 자동 실행됩니다. 빨간 **Stop** 버튼을 누르면 멈추고, 아래 Shell 창에 다음이 나오면 연결 성공입니다.

```
MicroPython v1.xx ... ESP32
Type "help()" for more information.
>>>
```

아무것도 안 나오면 Stop을 2~3번 더 누르거나, 케이블을 다시 꽂고 재시도합니다.

### 연결 확인 (선택)
Shell에 입력:

```python
import os; os.listdir()
```

`['boot.py', 'main.py', ...]`처럼 파일 목록이 나오면 됩니다. **View → Files**를 열면 로봇견 안의 파일이 보입니다. **지우거나 덮어쓰지 마세요.** (원래 `main.py`는 `firmware/backup/main_board_backup/`에 백업되어 있지만 로컬에만 있습니다.)

## 3. dog_cmd.py 실행

### 노트북 IP 확인 (`MONITOR`에 넣을 값)
- macOS: 터미널에서 `ipconfig getifaddr en0`
- Windows: `ipconfig` → Wi-Fi 어댑터의 IPv4 주소

### 코드 준비
1. Thonny **파일 → 새 파일**에 `firmware/dog_cmd.py` 내용을 붙여 넣습니다.
2. 위쪽 설정을 고칩니다.
   ```python
   WIFI_SSID = "YOUR_WIFI"          # 공유기 이름으로 바꾸기 (2.4 GHz)
   WIFI_PASS = "YOUR_PASSWORD"      # 공유기 비밀번호로 바꾸기
   MONITOR = ("192.168.0.11", 9000) # 노트북 IP
   NAME = "B"                       # A, B 또는 C
   ```
3. **저장소 안의 원본 파일에 비밀번호를 넣어 저장하지 마세요.** 새 파일에 붙여 넣어 쓰거나, 저장소 밖(바탕화면 등)에 저장합니다.

### 실행
**Run(F5)** 을 누릅니다. 로봇견 메모리에서만 실행되므로 원래 `main.py`는 바뀌지 않고, 로봇견을 껐다 켜면 원래 앱 조종 프로그램으로 돌아갑니다. Shell에 다음이 나오면 성공입니다.

```
Wi-Fi 연결됨, 로봇견 IP: 192.168.0.31
명령 대기: 192.168.0.31 9100
```

이 IP를 노트북 쪽 명령에 씁니다.

### dog_cmd.py가 하는 일
- 명령 실행: `{"cmd":"move","v":80,"turn":-20}` → `dog.move(80, -20)`, `{"cmd":"stop"}` → 정지
- 값 제한: 속도 ±120, 회전 ±50
- **워치독:** 1초 동안 명령이 없으면 정지
- **앞 장애물:** 초음파 15 cm 이내면 전진만 막음 (후진·회전은 허용)
- Wi-Fi가 끊기면 정지 후 재접속
- LED: 🟢 이동 중, 🟡 정지 명령, 🔴 앞이 막힘, 🔵 명령 없음
- 0.1초마다 대시보드로 상태, 초음파 거리, Wi-Fi 세기 전송

아직 없는 것: 넘어짐 감지(IMU), 배터리 읽기, 기본 액션(앉기 등).

## 4. 노트북에서 움직이기

노트북과 로봇견이 **같은 Wi-Fi 공유기**에 있어야 합니다.

### 방법 1: 키보드 조종
```bash
python brain/teleop.py --dog 192.168.0.31
```
작은 창이 뜨면 **그 창을 클릭한 상태에서** 키를 누릅니다(터미널이 아님).

| 키 | 동작 |
|---|---|
| `w` / `s` | 전진 / 후진 |
| `a` / `d` | 왼쪽 / 오른쪽 회전 |
| `q` / `e` | 전진하며 왼쪽 / 오른쪽 |
| 스페이스 | 정지 |
| `1` `2` `3` | 속도 단계 (60 / 90 / 120) |
| `x` | 종료 (정지 명령 보내고 끝냄) |

키를 누르고 있는 동안만 움직이고, 손을 떼면 0.3초 안에 멈춥니다.

### 방법 2: 마커 따라가기 (자동)
```bash
python brain/marker_follow.py --camera http://localhost:8000/api/camera/B/stream --dog 192.168.0.31 --show
```
일시정지 상태로 시작합니다. 화면에 `PAUSED - marker OK`가 뜨면 **스페이스(카메라 창) 또는 Enter(터미널)** 로 따라가기 시작, 다시 누르면 일시정지입니다.

### 방법 3: 직접 보내기 (테스트용)
```python
import socket, json, time
sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
DOG = ("192.168.0.31", 9100)

for _ in range(20):                       # 2초 동안 전진
    sock.sendto(json.dumps({"cmd": "move", "v": 80, "turn": 0}).encode(), DOG)
    time.sleep(0.1)
sock.sendto(json.dumps({"cmd": "stop"}).encode(), DOG)
```
명령을 한 번만 보내면 워치독 때문에 1초 뒤 멈춥니다. 계속 움직이려면 0.1초마다 반복해서 보내야 합니다.

## 5. 처음 움직여 볼 때 (안전 순서)

1. 배터리를 켜고 Run. 로봇견을 **들고 있거나 받침대에 올려 다리가 허공에 뜨게** 합니다.
2. `teleop.py` 실행 → 다리가 움직이는지 확인.
3. `a`를 눌렀을 때 **왼쪽으로 도는지** 확인. 반대면 이후 명령에 `--turn-sign -1`을 붙입니다.
4. 키에서 손을 떼면 멈추는지, teleop을 끄면 1초 안에 멈추는지 확인.
5. 초음파 앞에 손을 15 cm 안으로 대면 전진만 막히는지(LED 빨강) 확인.
6. 바닥에 내려놓고 속도 `1`단계부터 시험.

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| Thonny에 포트가 안 보임 | 데이터 케이블로 교체, 다른 USB 포트, CH340/CP210x 드라이버 설치 |
| `>>>`가 안 나옴 | Stop 여러 번, 케이블 다시 꽂기 |
| `ImportError: HW_MechDog` | 인터프리터가 MicroPython (ESP32)인지, 메인보드에 연결했는지 확인 |
| Wi-Fi 연결 실패 | 2.4 GHz 네트워크인지, 비밀번호 확인 |
| 실행하자마자 다리가 크게 움직임 | 정상(기본 자세 잡기). 그래서 들고 실행 |
| 명령을 보내도 안 움직임 | Shell에 IP가 나왔는지, `ping <로봇견 IP>`, 같은 Wi-Fi인지, 배터리 스위치가 켜졌는지 |
| LED 🔵 파랑 | 명령이 안 들어옴: IP·Wi-Fi 확인. 학교/회사 공유기는 기기끼리 통신을 막을 수 있음(AP 격리) → 개인 공유기나 휴대폰 핫스팟으로 시험 |
| LED 🔴 빨강 | 앞 15 cm 안이 막혀 전진만 막힌 상태 |
| LED 🟢 초록인데 안 걸음 | 명령은 받는 중. 배터리 부족이나 `move` 값 문제 |
| Wi-Fi 재접속 실패로 프로그램이 멈춤 | 로봇견은 정지 상태로 남음. Thonny에서 다시 Run |

Shell에 오류가 나오면 메시지를 그대로 복사해 두면 원인을 찾기 쉽습니다.
