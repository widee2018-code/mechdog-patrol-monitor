# 중간 시연 계획서 (2026-11-15): MechDog 3마리 행렬 따라가기 + 포위

시연할 것은 두 가지입니다.

1. **행렬 따라가기:** A(정찰견)를 키보드로 몰면 B가 A를, C가 B를 마커로 따라간다.
2. **포위와 재정렬:** A는 멈춰 있고, B는 오른쪽, C는 왼쪽으로 동시에 포위한다. 사람이 확인하고 명령하면 B, C 순서로 줄 자리에 돌아와 카메라로 방향을 맞춘다.

두 시연은 자동으로 이어지지 않습니다. **따라가기 프로그램을 끄고 → 포위 프로그램을 켜는** 수동 전환입니다.

---

## 1. 역할

| 사람 | 역할 | 하는 일 |
|---|---|---|
| `widee2018-code` | **운영** | 운영 노트북에서 모든 터미널 실행, 시연 진행 |
| `worksenddl2-source` | **관제 화면 · 촬영 · A 안전** | 대시보드를 보며 상태·이벤트 확인, 휴대폰으로 영상 촬영, A 옆에서 넘어짐 대비 |
| `jyj25` | **기록 · B·C 안전** | Supabase에 이벤트가 쌓이는지 확인(선택), 결과 표 기록, B·C 옆에서 넘어짐·충돌 대비 |

- 프로그램은 **운영 노트북 한 대**에서만 돌립니다. 다른 노트북은 대시보드 보기용입니다.
- 안전 담당은 로봇이 이상하게 움직이면 **"정지"라고 외치고** 로봇을 잡습니다. 운영자는 Ctrl+C를 누릅니다.

## 3. 사전 준비 (시연 30~40분 전)

### 3-1. 코드 받기 (운영 노트북)
```bash
cd "<저장소 폴더>/mechdog-patrol-monitor"
git checkout dev
git pull
pip install -r requirements.txt -r brain/requirements.txt
```

### 3-2. 노트북 IP 확인
```bash
ipconfig getifaddr en0        # macOS
# Windows: ipconfig → Wi-Fi 어댑터의 IPv4 주소
```

### 3-3. IP 기록표 (시연 장소에서 채우기)

| 장치 | IP | 확인 방법 |
|---|---|---|
| 운영 노트북 | | 위 명령 |
| 로봇견 A | | Thonny Shell `명령 대기: <IP> 9100` |
| 로봇견 B | | 〃 |
| 로봇견 C | | 〃 |
| 카메라 B | | 아래 3-4 |
| 카메라 C | | 아래 3-4 |

아래 명령의 `<A_IP>`, `<B_IP>`, `<C_IP>`, `<CAM_B_IP>`, `<CAM_C_IP>`, `<LAPTOP_IP>`를 이 표의 값으로 바꿉니다.

### 3-4. 카메라 2대를 Wi-Fi에 붙이기
- 카메라 펌웨어(`firmware/mechdog_cam/`)는 `secrets.h`에 적힌 Wi-Fi로만 접속합니다. **시연 장소 Wi-Fi가 다르면** `secrets.h`를 고쳐 Arduino IDE로 다시 업로드합니다 (README "카메라 펌웨어 교체").
- **C 카메라도 우리 펌웨어가 올라가 있는지 확인하세요.** 원래 Hiwonder 펌웨어면 자체 핫스팟으로만 동작합니다.
- IP 찾기: 업로드 후 Serial Monitor(115200)에 출력됩니다. 또는 노트북에서:
  ```bash
  # 같은 대역 전체에 ping을 한 번씩 보낸 뒤 목록 보기 (macOS, 대역은 노트북 IP에 맞게)
  for i in $(seq 2 254); do ping -c1 -t1 192.168.0.$i >/dev/null 2>&1 & done; wait; arp -a
  curl http://<CAM_B_IP>/status          # {"mode":"sta", ...}면 정상
  ```
- `mechdog-cam-a.local` 이름은 공유기에 따라 엉뚱한 주소로 가니 **IP를 직접 쓰세요**.

### 3-5. 로봇견 3마리에 `secrets.py` 저장 (개마다 한 번)
노트북의 `firmware/secrets.py`(git에 없음, 없으면 `secrets.py.example`을 복사)를 이렇게 채웁니다:
```python
WIFI_SSID = "YOUR_WIFI"          # 시연 장소 Wi-Fi 이름 (2.4 GHz)
WIFI_PASS = "YOUR_PASSWORD"      # 비밀번호
MONITOR = ("<LAPTOP_IP>", 9000)
NAME = "A"            # ← 개마다 A, B, C로 바꿔서 저장
```
1. 로봇견을 USB로 연결하고 Thonny에서 빨간 **Stop**.
2. `firmware/secrets.py`를 열고 `NAME`을 그 개 이름으로 바꿈.
3. **파일 → 다른 이름으로 저장 → MicroPython 장치 → `secrets.py`** (덮어쓰기 예).
4. Shell에서 확인: `import secrets; print(secrets.NAME, secrets.MONITOR)`
5. 다음 개로 반복. **NAME을 바꾸는 걸 잊으면 대시보드에서 개들이 섞입니다.**

### 3-6. 로봇견 3마리에서 `dog_cmd.py` 실행
1. 배터리 스위치 **ON**, 로봇을 들거나 받침대에 올려 둠 (켜면 일어서려고 움직임).
2. Thonny에서 `firmware/dog_cmd.py`를 열고 **Run**.
3. Shell에 `명령 대기: <IP> 9100`이 나오면 IP를 기록표에 적음.
4. USB를 뽑아도 되는지 확인: 로봇이 계속 서 있고, 노트북에서 `ping <IP>`가 응답하면 OK. 재부팅되면 USB를 꽂은 채로 진행.
5. 세 마리 모두 반복.

> **LED 색:** 파랑 = 명령 대기, 초록 = 움직이는 중, 빨강 = 앞이 막힘(15 cm), 꺼짐 = 프로그램 멈춤

### 3-7. 서버 켜기 (터미널 1, 시연 끝까지 켜 둠)
```bash
CAMERAS="B=http://<CAM_B_IP>:81/stream,C=http://<CAM_C_IP>:81/stream" \
  python -m uvicorn server.app:app --host 0.0.0.0 --port 8000 --timeout-graceful-shutdown 2
```
- Windows PowerShell:
  `$env:CAMERAS="B=http://<CAM_B_IP>:81/stream,C=http://<CAM_C_IP>:81/stream"; python -m uvicorn server.app:app --host 0.0.0.0 --port 8000 --timeout-graceful-shutdown 2`
- 브라우저에서 **http://localhost:8000** → 카메라 B, C가 "실시간"으로 나오고, 로봇견 카드 A·B·C에 Wi-Fi 세기가 보이면 정상.
- 다른 노트북(관제 화면·기록 담당)은 **http://<LAPTOP_IP>:8000** 으로 접속. 안 열리면 운영 노트북의 방화벽 확인.
- `Address already in use`가 나오면 서버가 이미 켜져 있는 것: 그 창을 쓰거나 Ctrl+C로 끄고 다시.

### 3-8. 회전 방향 확인 (A, B, C 각각, 1분씩)
```bash
python brain/teleop.py --dog <A_IP>
```
- 작은 창을 클릭한 상태에서 `a`(왼쪽 회전), `d`(오른쪽 회전)를 눌러 봄. 키를 떼면 0.3초 안에 멈춤. `x`로 종료.
- **반대로 돌면** 그 개는 이후 모든 명령에 `--turn-sign 1`을 붙입니다 (B는 -1로 확인됨).
- B, C도 `--dog <B_IP>`, `--dog <C_IP>`로 같은 확인.

| 개 | turn-sign |
|---|---|
| A | |
| B | -1 (2026-11-12 확인) |
| C | |

### 3-9. C 보정과 포위 경로 맞추기 (C만, 약 10분)
B는 `brain/calibration.json`에 보정값과 다듬은 경로가 있습니다. C는 처음입니다.
```bash
# 1) 제자리 회전(왼쪽·오른쪽 한 바퀴)과 1 m 직진 시간 재기
python brain/contain_demo.py calibrate --dog <C_IP> --name C
#    "왼쪽으로 돌았나요?"에 n이면 안내대로 --turn-sign 1 을 붙여 다시

# 2) C 혼자 포위 → 복귀 시험 (Enter 두 번)
python brain/contain_demo.py run --dog <C_IP> --name C --monitor 127.0.0.1

# 3) 어긋나면 값을 바꿔 다시 시험하고, 맞으면 --save로 저장
python brain/contain_demo.py run --dog <C_IP> --name C --monitor 127.0.0.1 \
    --out 0.5 --forward 0.5 --turn-in 95 --turn-back 185 --save
```
- `--out`: 옆으로 빠지는 거리 · `--forward`: 앞으로 가는 거리
- `--turn-in`: 포위 3번째 회전(다시 앞을 보는 회전) · `--turn-back`: 복귀 첫 회전(뒤로 돌기)
- 덜 돌면 각도를 늘리고, 더 돌면 줄입니다 (B는 100°, 190°였음).
- **보정이 끝나면 `brain/calibration.json`을 커밋**해 두면 다음부터 다시 안 해도 됩니다.

## 4. 시연 1: 행렬 따라가기

### 배치
```
   C ─ B ─ A  →  (진행 방향, 앞에 2~3 m 빈 공간)
```
- A 뒤에 B, B 뒤에 C. **앞 개 엉덩이에서 뒤 개 코까지 0.12~0.25 m**.
- B 카메라에 A의 마커 ID 1, C 카메라에 B의 마커 ID 2가 정면으로 보이게.

### 터미널 (운영 노트북)
| 터미널 | 명령 | 창 |
|---|---|---|
| 1 | 서버 (3-7, 켜져 있음) | |
| 2 | B 따라가기 | "marker follow - Dog B" |
| 3 | C 따라가기 | "marker follow - Dog C" |
| 4 | A 키보드 조종 | teleop 작은 창 |

```bash
# 터미널 2: B가 A(마커 1)를 따라감
python brain/marker_follow.py --camera http://localhost:8000/api/camera/B/stream \
    --dog <B_IP> --name B --monitor 127.0.0.1 --show

# 터미널 3: C가 B(마커 2)를 따라감 (C turn-sign이 1이면 --turn-sign 1 추가)
python brain/marker_follow.py --camera http://localhost:8000/api/camera/C/stream \
    --dog <C_IP> --name C --marker-id 2 --monitor 127.0.0.1 --show

# 터미널 4: A 조종 (A turn-sign이 1이면 --turn-sign 1 추가)
python brain/teleop.py --dog <A_IP>
```

### 진행
1. B, C 창이 **`STANDBY - READY for EXPLORE`(초록)** 가 될 때까지 기다림. 대시보드 타임라인에 "Dog B/C STANDBY: EXPLORE 준비 완료".
   - 빨강이면 아랫줄 이유를 보고 조정: `marker not seen`(마커 높이·방향), `gap 0.40 m`(간격), `dog not responding`(dog_cmd.py).
2. **C 창 클릭 → 스페이스**, **B 창 클릭 → 스페이스** (둘 다 "따라가는 중"). 이 상태에서 A가 안 움직이면 B, C도 제자리.
3. **teleop 창 클릭** → `1`(느린 속도) → `w`로 천천히 전진. 직진 1 m → 정지 → 살짝 회전(`q`/`e`) → 직진.
4. 끝나면 teleop에서 스페이스(정지) → `x`. B, C 창에서 **`q`** (정지 명령을 보내고 종료).

### 볼 것 · 기록
- B, C가 줄을 유지하며 따라오는 거리 (m), 놓친 횟수, 걷다 서다 정도
- 실패하면: 마커를 1.5초 넘게 놓치면 B·C는 마지막으로 본 쪽으로 제자리에서 천천히 돌며 찾음(12초 뒤 포기). **앞 개가 기다리는 기능은 아직 없으므로**, 놓치면 운영자가 A를 멈춤(teleop 스페이스).

## 5. 시연 2: 포위와 재정렬

### 전환
- **B, C 따라가기 창은 반드시 `q`로 끕니다.** 일시정지 상태에서도 정지 명령을 계속 보내서 포위 명령과 섞입니다.
- teleop도 `x`로 끕니다 (A는 그대로 서 있으면 됨).

### 배치
```
              B 도착 (오른쪽 0.2 m, 앞 0.2 m)
   C ─ B ─ A        ■ 침입자 상자 (A 앞 약 0.8 m)
              C 도착 (왼쪽, C 저장값)
```
- 따라가기 끝난 줄 그대로 두거나, A–B–C를 다시 일렬로 세움 (간격 0.12~0.25 m).
- B는 **오른쪽**(침입자 둘레 시계 반대), C는 **왼쪽**(시계)으로 빠짐. 양옆 1 m씩 비워 두기.

### 명령 (터미널 2 또는 5)
```bash
python brain/contain_demo.py run --name B,C --dog <B_IP>,<C_IP> --monitor 127.0.0.1 \
    --camera http://localhost:8000/api/camera/B/stream,http://localhost:8000/api/camera/C/stream
```
- 실행하면 B, C의 포위·복귀 동작 목록과 시간이 먼저 출력됩니다. 확인 후 진행.

### 진행
1. **Enter** → "침입자 발견": B·C가 **동시에** 포위 (대시보드 CONTAIN, 경보 이벤트).
   - B: 제자리 오른쪽 90° → 직진 0.2 m → 왼쪽 100° → 직진 0.2 m
   - C: 제자리 왼쪽 90° → 직진 → 오른쪽 회전 → 직진 (C 저장값)
2. **HOLD**: 둘 다 멈춤. 대시보드 "포위 완료, 확인 후 재정렬 명령 대기". 사람이 위치 확인·사진.
   - 위치가 많이 어긋났으면 이때 `python brain/teleop.py --dog <B_IP>`로 살짝 조정 후 `x` (HOLD 중에는 포위 프로그램이 명령을 안 보냄).
3. **Enter** → "재정렬": **B가 먼저** 복귀하고 카메라로 A 마커를 가운데 맞춤(최대 ±15°) → **그다음 C**가 복귀하고 B 마커를 맞춤.
4. "복귀 완료, B, C 다시 일렬 대기"가 나오면 끝. 다시 하려면 같은 명령을 다시 실행.

### 볼 것 · 기록
- 포위 지점 오차 (목표 대비 cm), 복귀 후 줄 자리 오차, 마커 정렬 성공 여부 (`가운데 정렬 완료` / `범위 밖`)
- 걸린 시간: 포위 약 20초, 복귀 약 40초 + 정렬 (개마다)

## 7. 문제 해결

| 증상 | 원인 · 해결 |
|---|---|
| 서버: `Address already in use` | 서버가 이미 켜져 있음. 그 창을 쓰거나 끄고 다시 |
| `No route to host` / `Host is down` | 로봇견 IP가 바뀌었거나 `dog_cmd.py`가 안 돎. Thonny Shell에서 IP 확인 후 다시 Run |
| 명령은 가는데 로봇이 안 움직임 | `dog_cmd.py` 멈춤 (LED 꺼짐). Thonny에서 Stop → Run. 배터리 스위치 확인 |
| Thonny: `secrets.py에 NAME ... 추가` | 그 개의 `secrets.py`에 `NAME` 줄이 없음. 3-5대로 다시 저장 |
| Thonny: `OSError: ENOMEM` | Wi-Fi가 느림. 최신 `dog_cmd.py`는 이걸로 죽지 않음 (git pull 확인). 공유기 가까이 |
| 따라가기 창: `dog not responding` | 서버에 그 개 상태가 안 옴: `secrets.py`의 `MONITOR`가 노트북 IP와 같은지, 서버를 최신 코드로 켰는지 |
| 따라가기 창: `marker not seen` | 마커 높이·각도·조명. 대시보드 카메라 화면으로 확인 |
| 마커 반대쪽으로 돎 | 그 개에 `--turn-sign 1` |
| 카메라 "오프라인" | 카메라 IP 확인 (3-4). 브라우저에서 `:81/stream`을 직접 열어 두면 서버가 못 받음(카메라는 한 곳에만 보냄) |
| 포위 명령인데 안 움직임 | 따라가기 창을 `q`로 안 끔 (정지 명령이 섞임) |
| `보정값이 없습니다` | 그 개 `calibrate` 먼저 (3-9) |
| 포위·복귀 각도가 계속 어긋남 | 그 개 단독으로 `--turn-in`, `--turn-back`, `--out`, `--forward` 조정 후 `--save`. 바닥이 바뀌었으면 `calibrate` 다시 |

## 8. 안전 수칙
- 운영자는 항상 **Ctrl+C**를 누를 준비. 모든 프로그램은 끝날 때 정지 명령을 보냅니다. 로봇 쪽도 1초 동안 명령이 없으면 스스로 멈춥니다.
- 처음 한 번은 **들고 있는 상태로** 명령을 보내 다리 움직임만 확인.
- 사람과 로봇 사이 30 cm 이상. 테이블 위에서는 시연하지 않음.
- 배터리 경고음이 나면 즉시 중단하고 충전.
