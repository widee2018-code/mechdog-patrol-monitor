지금 대시보드 진단

문제지금 화면새 시나리오에서 필요한 것
중요 예전 시나리오 기준 지도에 고정된 Pi + LiDAR 점, 소리 센서(ReSpeaker) 카드, 역할 "추적견·봉쇄견", 개별 순찰 구역 A·B·C A 등에 LiDAR, B·C는 마커를 따라 줄지어 걷기. 소리 센서 없음
중요 단계 이름이 다름 PATROL · SUSPECT · ALERT · INTERCEPT · CONTAIN · HANDOVER · RETURN (영어만) 지도 만들기 · 순찰 · 의심·확인 · 포위 · 인계 · 줄 다시 서기 (한글 + 영어)
중요 사건이 눈에 안 띔 경보가 떠도 위쪽 단계 표시만 깜빡임. 증거 사진은 맨 아래까지 스크롤해야 보임 화면 위 경보 띠(또는 사건 화면 전환), 경과 시간, 증거 사진 바로 보이기
중요 조작 버튼 없음 보기만 가능 전체 정지(비상), 일시정지·재개, 인계 완료 버튼
보통 카메라가 A 1대만 카메라 칸 하나 (LIVE_CAM = "A" 고정) A·B·C 3대. B·C 화면에서 앞 개의 마커 인식 상태가 보이면 좋음
보통 로봇견 정보가 한 줄에 몰림 위치·방향·앞거리·기울기·전압·Wi-Fi가 작은 회색 글씨 두 줄. 배터리 부족 경고색 없음. 로봇견이 보내지 않는 x, y는 "—"로 표시 배터리(색으로 경고), 앞 장애물, 상태, 마커 따라가기 거리를 큰 글씨로
보통 지도에 탐사 정보 없음 벽·장애물·LiDAR 점만 아는 곳/모르는 곳(지도 완성률), 이미 알린 물체 기억 표시, 따라가기 줄, 포위 위치·반경
작음 글씨가 작음 본문 11~13px. 프로젝터에서 3 m 떨어지면 읽기 어려움 중요한 숫자는 16px 이상
작음 연결 상태가 하나뿐 서버 연결(연결됨/끊김)만 표시 로봇견·카메라마다 온라인/오프라인

그대로 살릴 좋은 점: WebSocket 실시간 전송, 카메라를 서버가 한 번만 받아서 나눠 주는 구조(/api/camera/A/stream), 캔버스 지도, 인터넷 없이 동작(외부 라이브러리 없음), 오프라인 로봇견 자동 표시.
